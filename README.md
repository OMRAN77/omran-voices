# أصوات عمران

موقع خاص لعمران: تكتب الكلام وتسمعه بأي صوت ولغة، وتقدر تنسخ صوتك.

- **المحرك:** Chatterbox Multilingual (رخصة MIT، ٢٣ لغة منها العربي). الحين يشتغل عن طريق صفحته المجانية في Hugging Face.
- **كل شي يخص المحرك في ملف واحد:** `api/_engine.js`. لما يصير عندنا جهاز خاص، نبدّل هذا الملف بس.
- **الأصوات المحفوظة والسجل** تنحفظ في جهاز المستخدم (IndexedDB)، ما تنرفع لأي مكان إلا وقت التوليد.

## المتغيرات في Vercel

| الاسم | الشرح |
|---|---|
| `VOICES_ACCESS_KEY` | كلمة سر الموقع. بدونها الموقع يرفض أي طلب. |
| `HF_TOKEN` | مفتاح Hugging Face مجاني (Read). يعطي حد استخدام أكبر من بدون حساب. |

## القواعد

- ممنوع نسخ صوت أي شخص بدون موافقته، وممنوع نسخ أصوات ElevenLabs.
- ممنوع أي خدمة مدفوعة بدون موافقة عمران.
- هذا المشروع منفصل عن `omran-ai-builder` وما يلمسه.
